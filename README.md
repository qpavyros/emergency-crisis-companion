## 🇸🇦 باللغة العربية

### 📌 نبذة عن المشروع
**EmergencyKit PWA** هو تطبيق ويب مفتوح المصدر يعمل **100% بدون إنترنت (Offline-First)** مصمم خصيصاً لمساعدة المسعفين، فرق الإنقاذ، المتطوعين، والسكان أثناء الكوارث الطبيعية، الحروب، والنزاعات عند انقطاع الاتصالات والإنترنت.

### 🌟 الميزات الرئيسية:
1. **🏥 نظام الفرز الطبي الميداني السريع (START Triage Protocol)**: دليل تفاعلي لفرز المصابين وتصنيفهم حسب خطورة الإصابة خلال 60 ثانية (أحمر، أصفر، أخضر، أسود).
2. **🌐 المترجم الطبي البصري الميداني**: عبارات طبية أساسية مترجمة مع نطق صوتي وصوري (عربي، إنجليزي، فرنسي، إسباني، تركي، أوكراني).
3. **🩸 أدلة الإسعافات الأولية الشديدة**: إرشادات خطوة بخطوة للتحكم بالنزيف الحاد، الإنعاش القلبي (CPR)، الحروق والكسور.
4. **📢 صفارة ووميض استغاثة (SOS Beacon)**: توليد صفارة إنذار عالية التردد باستخدام Web Audio API مع وميض شاشة لتحديد موقع المحاصرين.
5. **📍 محدد الإحداثيات الميداني (Offline GPS)**: جلب إحداثيات الموقع مباشرة عبر الأقمار الاصطناعية.

### 🚀 كيفية الرفع على GitHub والمشاركة:
1. افتح مبسط الأوامر في مجلد المشروع وشغّل:
```bash
git init

```
2. أنشئ مستودعاً جديداً على GitHub باسم `emergency-crisis-companion`.
3. اربط المستودع وارفع الكود:
```bash

```
4. لتشغيل الموقع مجاناً للجميع عبر **GitHub Pages**:
   - اذهب إلى إعدادات المستودع (Settings) -> Pages.
   - اختر الفرع `main` واضغط **Save**.
   - سيتوفر رابط التطبيق مجاناً لأي شخص في العالم ومتح بالكامل بدون إنترنت!

## 🇬🇧 English

### 📌 About
**EmergencyKit PWA** is an open-source, offline-first Web Application built for field humanitarian workers, rescue teams, and survivors during emergency blackouts, natural disasters, or conflict zones.

### 🌟 Key Features:
- **START Triage Wizard**: Quick 60-second mass casualty field triage (Red, Yellow, Green, Black categories).
- **Offline Medical Translator**: Multi-lingual emergency medical phrasebook (Arabic, English, French, Spanish, Turkish, Ukrainian).
- **Critical First-Aid Guides**: Hemorrhage control, CPR, severe burn management, fracture immobilization.
- **Audio & Visual SOS Beacon**: High-frequency synthesizer siren & flash light for search and rescue.
- **Satellite GPS Coordinate Reader**: Instant geolocation display without cellular data.
